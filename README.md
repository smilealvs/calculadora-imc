# Calculadora de IMC

Uma aplicação web para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura, apresentando o resultado e sua respectiva classificação.

## Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em desenvolvimento web, com o objetivo de praticar lógica de programação em JavaScript e explorar a construção de interfaces modernas com HTML e CSS.

A lógica de cálculo e classificação do IMC foi desenvolvida manualmente, enquanto a interface visual foi construída com auxílio de ferramentas de inteligência artificial.

## Funcionalidades

- Cálculo do IMC com base no peso e na altura.
- Classificação do resultado de acordo com as faixas de IMC.
- Seleção de unidade para estatura (centímetros ou metros com conversão automática).
- Validação dos valores informados.
- Apresentação visual do resultado com régua linear interativa.
- Alternância entre temas claro e escuro.
- Interface responsiva com rolagem suave em dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Desenvolvimento com IA

A inteligência artificial foi utilizada como ferramenta de apoio durante o desenvolvimento da interface, auxiliando na implementação visual e na construção da experiência do usuário.

A lógica principal do cálculo foi desenvolvida manualmente, como parte do processo de aprendizado e prática de JavaScript.

## Observação

O IMC é um indicador geral e não deve ser utilizado isoladamente para avaliar a saúde ou estabelecer diagnósticos.
